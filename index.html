Phone reminders (iPhone Shortcuts)

Make 5 automations in the Shortcuts app. Each one sends a notification, and tapping it opens a drill here.

  1. Open Shortcuts → Automation tab → + (or "New Automation").
  2. Choose Time of Day. Set the time, pick Weekly, and select Mon–Fri.
  3. Choose Run After Confirmation. This is what makes a notification pop up. Tap Next.
  4. Pick New Blank Automation, add the Open URLs action, and paste the link for that time from the list below.
  5. Tap Done. Do this for all 5 times.

Tip: tap a link to copy it. Menu names can differ slightly between iOS versions.
